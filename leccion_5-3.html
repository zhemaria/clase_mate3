Lección 5.3 · Despeje de fórmulas literales y estrategia general de resolución

4 horas (2 sincrónicas + 2 asincrónicas) · NRS 3–4 · Brightspace D2L

Objetivos de la lección

  • Despejar una variable específica en una fórmula literal usando las propiedades de igualdad.
  • Tratar las demás letras de la fórmula como si fueran constantes.
  • Aplicar una estrategia general de cuatro pasos para despejar.
  • Usar la fórmula despejada para resolver un problema de contexto.
  • Reconocer las fórmulas de uso frecuente en el GED.

Conexión con la lección anterior. A lo largo del Tema 4 y la primera parte del Tema 5 se resolvieron ecuaciones e inecuaciones para encontrar el valor de x. Despejar una fórmula es exactamente lo mismo, con una diferencia: la variable que se busca está rodeada de otras letras en lugar de números. Como dice la idea clave, «despejar es resolver una ecuación donde la variable es un símbolo, no un número».

1. ¿Qué es despejar una fórmula?

Una fórmula literal relaciona varias cantidades con letras, como d = rt (distancia = rapidez × tiempo). Despejar una de ellas significa reescribir la fórmula para que esa variable quede sola de un lado. Las demás letras se tratan como si fueran números conocidos.

Ejemplo 1

En d = rt, despejar t.

1 La t está multiplicada por r. Para aislarla, se divide entre r en ambos lados.
2 d/r = t.

Respuesta: t = d/r.

Las otras letras son «números»: al despejar t en d = rt, la r se trata igual que un número. Dividir entre r es como dividir entre 5 o entre cualquier número: una operación inversa para aislar la variable buscada.

2. La estrategia de cuatro pasos

Para despejar cualquier variable se sigue siempre la misma secuencia.

Cuatro pasos para despejar:
  1. Identificar qué variable se quiere despejar.
  2. Aislarla con las propiedades de igualdad (operaciones inversas), tratando las demás letras como números.
  3. Simplificar el resultado, con fracción si es necesario.
  4. Verificar que la variable buscada quedó sola de un lado.

4. Fórmulas de dos pasos

Algunas fórmulas requieren más de una operación para despejar, igual que las ecuaciones de varios pasos. Se deshacen las operaciones en orden inverso.

Ejemplo 4 · Temperatura

En F = (9/5)C + 32, despejar C.

1 Se resta 32 en ambos lados: F − 32 = (9/5)C.
2 Se multiplica por 5/9 en ambos lados para deshacer el (9/5): (F − 32) · 5/9 = C.

Respuesta: C = (F − 32) · 5/9.

Ejemplo 5 · Recta

En y = mx + b, despejar b.

1 Se resta mx en ambos lados.

Respuesta: b = y − mx.

Orden inverso: en F = (9/5)C + 32, primero se quita el «+ 32» (resta) y luego el «× 9/5» (multiplicación por el recíproco). Es el mismo orden inverso de las ecuaciones de dos pasos.

5. Aplicar la fórmula despejada

Una vez despejada, la fórmula sirve para calcular la variable buscada sustituyendo los valores conocidos.

Ejemplo 6

Un auto recorrió d = 120 km a una rapidez de r = 40 km/h. ¿Cuánto tiempo tardó?

1 Se usa la fórmula despejada: t = d/r.
2 Se sustituye: t = 120 / 40 = 3.

Respuesta: el auto tardó 3 horas.

Conexión con la física: la misma idea aplica a F = ma (fuerza = masa × aceleración). Para hallar la aceleración a, se despeja a = F/m. Despejar es una herramienta general que aparece en geometría, finanzas y ciencias.

6. Práctica guiada en clase

Las siguientes tres actividades se realizan durante las horas sincrónicas. Cada una se presenta en doble modalidad: una versión para el aula presencial y otra para la sesión en línea.

Actividad 1 · El kit de fórmulas del GED

🏫 Presencial

Con la tabla de fórmulas frecuentes a la vista, cada estudiante despeja una variable distinta de cada una de las ocho fórmulas, anotando junto a cada paso la propiedad de igualdad usada.

💻 En línea

En un documento compartido, los estudiantes completan una tabla de tres columnas (fórmula, variable a despejar, fórmula despejada) para las ocho fórmulas del kit.
Actividad 2 · Despejar y aplicar

🏫 Presencial

Los estudiantes despejan la variable pedida en cuatro fórmulas y, a continuación, usan la fórmula despejada para resolver un problema de contexto con valores numéricos. Un voluntario muestra un caso completo en la pizarra.

💻 En línea

En salas pequeñas, las parejas despejan dos fórmulas y aplican cada una en un problema numérico, registrando el despeje y el cálculo en una hoja compartida.
Actividad 3 · ¿Qué necesito saber?

🏫 Presencial

A partir de fórmulas como F = ma o I = Prt, los estudiantes determinan qué variable hay que despejar y qué datos hacen falta para encontrarla, conectando el despeje con situaciones de física y finanzas.

💻 En línea

Cada estudiante elige dos fórmulas, indica en el chat qué variable despejaría según una pregunta dada y qué datos necesitaría para calcularla.
