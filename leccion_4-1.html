Conexión con el nivel anterior. El lenguaje algebraico no es del todo nuevo: en el Nivel 1 ya se trabajó con incógnitas simples para resolver problemas de un paso. Lo que cambia aquí es la profundidad. Tras completar el sentido numérico en los Temas 1 al 3 de este nivel (exponentes, notación científica y números reales), el Nivel 3 retoma y formaliza ese lenguaje: se trabajará la traducción completa entre palabras y símbolos, y se aprenderá a simplificar expresiones distribuyendo y combinando términos semejantes. Esa base permitirá, en las próximas lecciones, resolver ecuaciones.

1. Variables, términos y coeficientes

Una variable es una letra que representa un número desconocido o que puede cambiar. Una expresión algebraica combina variables, números y operaciones. Sus partes tienen nombres precisos:

Partes de la expresión 3x más 5: término, coeficiente, variable y constante.
Parte En 3x + 5 Significado
Término3x y 5Cada parte separada por + o −.
Coeficiente3El número que multiplica a la variable.
VariablexLa letra que representa el valor desconocido.
Constante5El término que no tiene variable.
Coeficiente invisible: cuando una variable aparece sola, como x, su coeficiente es 1 (x = 1x). De igual modo, −x significa −1x. Recordarlo evita errores al combinar términos.

2. Traducir entre palabras y álgebra

Gran parte del álgebra consiste en traducir un enunciado verbal al lenguaje de los símbolos. Ciertas palabras señalan siempre la misma operación.

Tabla de traducción del lenguaje verbal al algebraico.
Frase verbal Expresión algebraica
El doble de un número x2x
Tres más que un número xx + 3
La mitad de un número xx/2
Un número x disminuido en 4x − 4
El cuadrado de un número xx²
Cinco veces un número, aumentado en 25x + 2
El orden importa en la resta: «un número disminuido en 4» es x − 4, pero «4 disminuido en un número» es 4 − x. La resta no es conmutativa, así que conviene leer con cuidado quién va primero.

3. Combinar términos semejantes

Dos términos son semejantes si tienen la misma variable elevada al mismo exponente. Solo los términos semejantes se pueden combinar, sumando o restando sus coeficientes.

Ejemplo 1

Simplificar 3x + 5x.

1 Ambos términos tienen la variable x: son semejantes.
2 Se suman los coeficientes: 3 + 5 = 8.

Respuesta: 3x + 5x = 8x.

Ejemplo 2 · Con constante

Simplificar 7x − 2x + 4.

1 Los términos con x son semejantes: 7x − 2x = 5x.
2 El 4 es una constante: se deja aparte.

Respuesta: 7x − 2x + 4 = 5x + 4.

No se combinan términos distintos: 4x + 2y no se puede simplificar, porque x y y son variables diferentes. Tampoco 3x + 5 se reduce a 8x, porque 5 no tiene la variable x.

4. La propiedad distributiva

La propiedad distributiva permite multiplicar un número por una suma, repartiéndolo a cada término del paréntesis.

a(b + c) = a · b + a · c

Ejemplo 3

Simplificar 3(x + 4).

1 Se reparte el 3 a cada término: 3 · x + 3 · 4.

Respuesta: 3(x + 4) = 3x + 12.

Ejemplo 4 · Distribuir y combinar

Simplificar 2(x + 3) + 4x.

1 Se distribuye: 2x + 6 + 4x.
2 Se combinan los términos semejantes: 2x + 4x = 6x.

Respuesta: 2(x + 3) + 4x = 6x + 6.

5. Evaluar expresiones

Evaluar una expresión significa sustituir la variable por un valor dado y calcular el resultado, respetando el orden de las operaciones (PEMDAS).

Ejemplo 5

Evaluar 2x + 5 cuando x = 3.

1 Se sustituye x por 3: 2(3) + 5.
2 Se multiplica primero: 6 + 5.

Respuesta: 2x + 5 = 11 cuando x = 3.

Ejemplo 6 · Con exponente

Evaluar x² + 1 cuando x = 4.

1 Se sustituye: (4)² + 1.
2 Se calcula la potencia primero: 16 + 1.

Respuesta: x² + 1 = 17 cuando x = 4.

Usar paréntesis al sustituir: escribir 2(3) en lugar de 23 evita confundir la multiplicación con un número de dos dígitos. Es especialmente importante al sustituir valores negativos o fraccionarios.

Cierre y enlace con la próxima lección

En esta lección se retomó y formalizó el lenguaje algebraico iniciado en el Nivel 1: una variable representa una cantidad desconocida, y con ella se escriben expresiones que se traducen del lenguaje verbal, se simplifican combinando términos semejantes y aplicando la propiedad distributiva, y se evalúan sustituyendo valores.

En la Lección 4.2 · Resolver ecuaciones lineales: propiedades de igualdad y variables en ambos lados se dará el siguiente paso: cuando una expresión se iguala a otra, aparece una ecuación, y el objetivo será encontrar el valor de la variable que la hace verdadera. Simplificar y combinar términos, como se aprendió aquí, será el primer paso de toda resolución.
