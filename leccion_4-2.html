Lección 4.2 · Resolver ecuaciones lineales: propiedades de igualdad y variables en ambos lados

Conexión con la lección anterior. En la Lección 4.1 se aprendió a simplificar y evaluar expresiones algebraicas. Cuando dos expresiones se unen con un signo de igual, se forma una ecuación: 2x + 3 = 11. A diferencia de una expresión, una ecuación tiene una solución —el valor de la variable que la hace verdadera—, y esta lección enseña a encontrarla de forma metódica.

1. La ecuación como una balanza

Una ecuación es como una balanza en equilibrio: lo que está a la izquierda del signo igual pesa lo mismo que lo que está a la derecha. Para mantener el equilibrio, cualquier operación que se haga en un lado debe hacerse igual en el otro. Esa es la idea de las propiedades de igualdad: se puede sumar, restar, multiplicar o dividir ambos lados por el mismo número.

El objetivo siempre es el mismo: dejar la variable sola de un lado del igual (aislarla). Cada operación que se aplica busca deshacer lo que rodea a la variable, usando la operación inversa.

2. Aislar la variable: ecuaciones de uno y varios pasos

Se deshacen las operaciones en orden inverso al de PEMDAS: primero la suma o resta, luego la multiplicación o división.

Ejemplo 1 · Un paso

Resolver x + 7 = 15.

1 Para deshacer «+ 7», se resta 7 en ambos lados: x + 7 − 7 = 15 − 7.

Respuesta: x = 8.

Ejemplo 2 · Dos pasos

Resolver 2x + 5 = 13.

1 Se resta 5 en ambos lados: 2x = 8.
2 Se divide entre 2 en ambos lados: x = 4.

Respuesta: x = 4.

Orden inverso: en 2x + 5, la variable está primero multiplicada por 2 y luego se le suma 5. Para deshacerlo se procede al revés: primero se quita el +5 (resta) y al final el ×2 (división).

3. La estrategia de cinco pasos

Para cualquier ecuación lineal, esta lista ordenada funciona como una guía confiable.

Cinco pasos para resolver una ecuación:
  1. Distribuir los paréntesis, si los hay.
  2. Combinar los términos semejantes de cada lado.
  3. Pasar las variables a un solo lado del igual.
  4. Aislar la variable con las propiedades de igualdad.
  5. Verificar sustituyendo la solución en la ecuación original.

4. Variables en ambos lados

Cuando la variable aparece en los dos lados del igual, primero se reúnen todas las variables en un solo lado (restando una de ellas en ambos lados) y todas las constantes en el otro. Después se aísla la variable como siempre.

Ejemplo 3

Resolver 5x + 2 = 3x + 10.

1 Se resta 3x en ambos lados para reunir las variables: 2x + 2 = 10.
2 Se resta 2 en ambos lados: 2x = 8.
3 Se divide entre 2: x = 4.

Respuesta: x = 4.

Ejemplo 4

Resolver 7x + 1 = 2x + 16.

1 Se resta 2x en ambos lados: 5x + 1 = 16.
2 Se resta 1 en ambos lados: 5x = 15.
3 Se divide entre 5: x = 3.

Respuesta: x = 3.

Truco práctico: conviene mover las variables al lado donde el coeficiente quede positivo. En el Ejemplo 3, restar 3x (el menor) deja 2x positivo, lo que evita trabajar con un coeficiente negativo.

5. Verificar la solución

Toda solución se comprueba sustituyéndola en la ecuación original. Si ambos lados dan el mismo valor, la solución es correcta.

Ejemplo 5 · Verificación

Comprobar que x = 4 resuelve 2x + 1 = 9.

1 Se sustituye x por 4: 2(4) + 1.
2 Se calcula: 8 + 1 = 9.

Respuesta: el lado izquierdo da 9, igual que el derecho: la solución x = 4 es correcta.

Verificar no es opcional: sustituir la solución es la mejor forma de detectar un error de signo cometido durante el proceso. Un minuto de verificación evita perder todos los puntos del problema.
